# Meu site de portfólio

> Protótipo: isto é um teste da Itera, ainda não é um produto.

## O que você vai construir

Um site só seu, sobre você e seus projetos, que qualquer pessoa pode abrir
pelo celular. Você escreve tudo em 3 arquivos:

- `index.html`: o que aparece na página (textos, links, imagens)
- `styles.css`: como a página fica bonita
- `script.js`: o que acontece quando alguém clica

## Os 5 passos

1. **Estrutura**: monte o esqueleto da página no `index.html`.
2. **Conteúdo**: escreva sobre você, liste seus projetos (com links) e coloque uma imagem.
3. **Estilo**: ligue o `styles.css` e deixe o site com a sua cara.
4. **Interação**: faça um botão que troca o tema (claro e escuro) do site.
5. **Publicar**: coloque o site no ar com o GitHub Pages.

Dentro dos arquivos tem comentários `TODO` dizendo o que fazer em cada passo.

## Como ver se você acertou

Toda vez que você salva suas mudanças no GitHub, um robô confere o seu site.

1. Abra o seu repositório no GitHub.
2. Clique na aba **Actions**.
3. Clique na rodada mais recente (a primeira da lista).
4. Você vai ver 5 itens, de `step-1` a `step-5`:
   - verde: esse passo está certo
   - vermelho: falta algo. Clique nele para ler o que falta e qual lição da Itera revisar
   - o passo 5 fica aguardando até você ligar o GitHub Pages

O robô diz **o que falta**, nunca a resposta pronta. Isso faz parte de aprender.

## Passo 5: ligar o GitHub Pages

No seu repositório: **Settings**, depois **Pages**, e em **Source** escolha **GitHub Actions**.
Faça uma nova mudança qualquer e salve. Em alguns minutos o site fica em
`https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
